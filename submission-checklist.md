# Submission Checklist

Use this checklist before uploading to Moodle.

## Android Project

- Full Android Studio project folder included.
- Java source code included.
- XML layouts included.
- `README.md` included.
- `build/`, `.gradle/`, and generated temporary folders excluded.

## GitHub

- Repository is public, or marker is added as collaborator if private.
- At least 10 meaningful commits are visible.
- README explains the app, database choice, and run steps.
- GitHub link is placed in the written report.

## Video

- Length is between 5 and 7 minutes.
- Voice narration is included throughout.
- GitHub commit history is shown.
- CRUD is demonstrated.
- Strict matching is demonstrated by adding/removing an ingredient.
- Persistence is shown by closing and reopening the app.
- Code explanation includes database, adapter/Intents, and strict matching.
- Video file is exported as compressed MP4 and placed inside the final ZIP.

## Written Report

- Cover page completed.
- Table of contents included.
- Introduction written.
- Screen flow diagram included.
- Database/ER diagram included.
- Screenshots with captions included.
- 3 to 5 code snippets explained.
- Challenges and solutions included.
- Conclusion and reflection included.
- References included in Harvard style.

## Final ZIP

- ZIP name format: `Studentnumber_Surname_MobileAppDev700_Assignment.zip`
- Report name format: `Studentnumber_Surname_MobileAppDev700_Assignment.docx`
- ZIP contains project, report, and video.
- ZIP is under 50MB.
